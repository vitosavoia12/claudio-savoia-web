# Sitio de Claudio Savoia

Sitio estático preparado para GitHub Pages. No necesita instalar ni compilar nada.

## Publicarlo

1. Crear un repositorio nuevo en GitHub.
2. Subir `index.html` y la carpeta `images` a la raíz del repositorio.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama `main`, la carpeta `/ (root)` y guardar.

GitHub mostrará la dirección pública del sitio después de unos minutos.
